# 행사 운영 플랫폼

여러 축제에 재사용하는 모바일 웹 앱과 부스·운영본부 관리 화면입니다. 기존 클릭형 시안과 달리 Python API와 SQLite에 실제 데이터를 저장합니다. 현재는 로컬 개발·검토용 구현이며, 행사 배포·1만 명 규모 검증 완료 상태가 아닙니다.

## 다른 컴퓨터에서 이어서 작업

```bash
git clone https://github.com/polarking1115/GPS.git
cd GPS
git switch main
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

Windows에서는 `python3` 대신 `py -3.12`, `.venv/bin/python` 대신 `.venv\Scripts\python.exe`를 사용하세요. 비공개 저장소인 경우 해당 GitHub 계정으로 인증해야 합니다.

실행 후 브라우저에서 `http://127.0.0.1:8000`을 열고, `/manage`에서 새 개발 환경의 첫 관리자 계정을 생성합니다.

**GitHub에는 코드·문서·디자인만 포함됩니다.** 기존 `.data/` 개발 DB·암호키·계정·환경 변수는 포함되지 않습니다. 새 컴퓨터에서는 샘플 데이터로 시작합니다. 기존 개발 데이터까지 옮길 필요가 있다면 비공개 백업의 DB와 encryption.key를 함께 안전한 경로로 옮겨야 하며 Git에 추가하면 안 됩니다.

이어서 할 일은 [작업 재개 메모](docs/RESUME.md), 구현 범위는 [구현 현황](docs/implementation-status.md), 외부 서비스 후보는 [연동 검토](docs/integration-options.md)를 확인하세요.

## 실행

Python 3.12 이상에서:

```bash
cd /workspace/GPS
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

기본 주소는 `http://127.0.0.1:8000`입니다.

- `/`: 공개 행사 선택 및 참가자 앱
- `/manage`: 운영본부. 최초에는 **로컬 접속에서 첫 관리자 생성**. 이메일·표시명·12자 이상 비밀번호를 직접 지정합니다. 기본 비밀번호는 없습니다.
- `/register?event=youth-expo`: 부스 등록
- `/booth`: 부스 공동 관리 로그인
- `/bm/<관리 코드>`: 담당자 전용 주소. 공통 비밀번호와 담당자 표시명으로 접속
- `/b/<인증 코드>`: 현장 부스 QR 인증. 인증 코드는 공개 부스 API에 포함하지 않습니다.
- `/e/<행사 ID>`: 행사별 참가자 화면
- `/invite?code=<초대 코드>`: 24시간 유효·1회용 운영자 초대

최초 샘플 행사 `youth-expo`는 현재 한국 날짜로 생성되어 로컬 인증 테스트를 할 수 있습니다. 실제 행사 날짜·내용으로 변경하세요. 샘플 부스 비밀번호는 무작위이며 알 수 없게 설정합니다. 총괄이 **공간·부스 → QR·접근 → 공통 비밀번호 초기화**에서 설정해야 합니다. 참가 인증 QR도 여기서 다운로드할 수 있습니다.

## 구현한 흐름

- 행사 개설·설정 복제(존·부스·지도·미션·프로그램·설문), 초대·행사별 역할, 작업 이력
- 존과 부스 등록·승인·정보 수정, 여러 기기의 부스 공동 관리, 비밀번호 변경 시 기존 세션 회수
- 키비주얼 이미지·대표 색상 등록, 앞서 검토한 청록·파랑 계열 참가자 UI
- 부스 고정 QR SVG 다운로드와 브라우저 인쇄/PDF 저장
- 초기 개인정보 입력 없이 패스 생성, HttpOnly 쿠키 연결, 복구 기능 없음
- 서버 운영 상태·기간 확인, 동시 재시도 중복 방지, 별점 또는 평가 없이 인증
- 일별/행사 누적 부스 고유 패스 집계, 존은 부스별 참여자 합계, 평가 수·분포
- 부스/존 개수 미션, 퀴즈, 글 제출·운영자 검토
- 프로그램 일정·관심 일정(기기 저장), 공지
- 전체 설문 붙여넣기 인식 초안·표준 문항 추가·편집·공개, 응답 후 문항 변경 차단
- 행사별 설문·응모 조건, 연락처 정규화+HMAC 해시 기반 최초 유효 응모 1건
- 추첨 마감 확인·무작위 추첨·재추첨 차단·실행 대상 기록, 상품권 CSV·발송 결과 관리
- 대상별 업무 알림·부스 단위 확인, 유형별 문의·대화·처리 상태
- 지정 권한 안전 신고·답변·열람 이력. **기본 비활성**이며 현장 대응 준비 후 활성화
- 부스당 운영 실적 설문, 참가자 설문 집계·본인 지출 합계, 부스 CSV·보고서 인쇄
- 건물별 통합 평면도 업로드·부스 클릭 배치·확대. 층 선택 없음
- 등록된 야외 보행 지점/통로의 최단 경로·거리·GPS 기반 가까운 출발지 제안
- 공개 API, 같은 출처에서 사용할 수 있는 부스 목록 위젯
- 한국어·영어 기본 메뉴, 타 언어 Chrome 번역 안내
- 공개 안내·이미지의 오프라인 캐시. 개인정보 API·응모·신고는 캐시하지 않음

## 미연결 또는 추가 제작 대상

사용자 기획에서 제외한 것이 아니라, 현재 구현 범위를 투명하게 구분한 목록입니다. [구현 현황](docs/implementation-status.md)을 참고하세요.

- 지도 공급자·위성 타일·상용 보행 API, 위성지도 위 배치도 정렬·회전·투명도, GPS 자동 실내외 전환: 미연결. 현재 야외는 등록 보행로 **개략도**이며 위성지도가 아닙니다.
- 번역 API·행사 콘텐츠 영어 자동 번역·검토·버전 관리: 미연결. 기본 메뉴만 영어 제공하며 번역 미연결 안내가 표시됩니다.
- 날씨·공식 기상특보 API: 미연결. 임의 날씨를 실제 정보로 표시하지 않습니다.
- 상품권 구매·자동 발송 API: 미연결. 외부 서비스용 CSV와 수동 결과 기록 제공.
- 탄소 배출/감축·사회적 편익·지역경제 확대 추정: 계수·기준 검증 전 산정하지 않습니다. 설문 수집·기초 집계만 작동합니다.
- 만 14세 미만 설문: 법정대리인 동의 확인 구현 전 **개인정보 설문 제출 차단**. 일반 안내·참여는 유지됩니다.
- 신고 사진·동의 예외 연락처, 파일첨부 메시지, 웹 푸시·예약 공지·재알림·입력 중 표시·문의 사진: 추가 제작.
- 미션 사진·글 재제출 요청·예비 당첨 승계·연락처 정정·정교한 데이터 삭제/보관 스케줄: 추가 제작.
- 외부 홈페이지 iframe: 기본 CSP는 `frame-ancestors 'self'`. 실제 아임웹 도메인을 확인하고 `FESTIVAL_EMBED_ORIGINS=https://your-site.imweb.me`로 허용 출처를 지정하세요. 해당 출처에만 iframe과 공개 GET API CORS를 허용합니다. 임의 `*` 허용은 하지 않습니다.

## 보안·운영

- `.data/`는 비공개 데이터·암호키·DB/WAL 저장소입니다. Git에서 제외하며 디렉터리 0700, 키 0600을 사용합니다. **암호키가 사라지면 암호화한 자료를 복구할 수 없습니다.** DB와 키를 접근 제한된 백업으로 함께 보관하세요.
- 연락처·설문 원자료·민감 신고 본문은 Fernet 암호화, 중복 판정 번호는 HMAC 해시, 비밀번호는 scrypt 해시로 저장합니다. 메모리·다운로드·백업·관리자의 접근 정책은 별도로 필요합니다.
- 참가자 쿠키는 HttpOnly·SameSite=Lax. HTTPS 배포 시 `FESTIVAL_SECURE_COOKIE=1`을 설정하세요. 운영자 토큰은 탭의 sessionStorage에 12시간 유효하게 보관합니다.
- 민감 신고는 `support` 권한으로만 열람합니다. 총괄도 이 권한을 별도로 받아야 합니다. 참가자는 자기 세션의 답변만 조회합니다.
- 참가자 고유 패스는 실제 사람 신원 인증이 아닙니다. 연락처 입력도 소유 확인을 보장하지 않습니다. 중복 응모 정책은 번호 기준입니다.
- 첫 관리자 설정은 기본 loopback 바인딩에서만 사용하세요. 인터넷 공개 전 관리자 생성 후 `FESTIVAL_ALLOW_SETUP=0`, HTTPS 역방향 프록시, 원본 접근 차단, 백업·모니터링·부하 검증을 적용하세요. 기본 HTTP 서버는 개발용입니다.
- 개인정보 동의문·연령 처리·보관 기간은 운영자가 적법한 내용을 검토해 설정해야 합니다. 설문은 동의문 없이는 공개되지 않습니다. 법적 검토 완료를 뜻하지 않습니다.
- 서버 로그에는 요청 URL·본문·토큰을 출력하지 않습니다. 민감 원자료 삭제는 되돌릴 수 없으며 백업·내려받은 파일 삭제는 별도입니다.

## 검증

```bash
cd /workspace/GPS
.venv/bin/python -m unittest discover -s tests -v
node --check public/app.js
```

통합 테스트는 임시 DB와 별도 HTTP 서버를 사용하고 종료 후 정리합니다. QR 재시도/동시성·권한·미션·설문·중복 연락처·신고·추첨을 검증합니다.

브라우저 테스트는 Playwright와 Chromium이 있는 개발 환경에서 **새 임시 DB 서버**를 별도로 실행한 뒤 수행합니다. 실제 행사 DB에서는 실행하지 마세요.

```bash
FESTIVAL_DATA=/tmp/festival-browser-test PORT=8001 .venv/bin/python server.py
# 다른 터미널에서
BROWSER_TEST_URL=http://127.0.0.1:8001 node tests/browser-check.cjs
```

브라우저 검증은 실제 setup·로그인·인증·운영 중단·설문·문의·문항 편집과 모바일 넘침을 확인합니다. 이것은 1만 명 부하 검증이나 외부 서비스 연동 검증이 아닙니다.
