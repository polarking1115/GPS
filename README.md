# 행사 운영 플랫폼

여러 축제에 재사용하는 모바일 웹 앱과 부스·운영본부 관리 화면입니다. 기존 클릭형 시안과 달리 Python API와 SQLite에 실제 데이터를 저장합니다. 현재는 로컬 개발·검토용 구현이며, 행사 배포·1만 명 규모 검증 완료 상태가 아닙니다.

## 무료 테스트 배포

[Render에서 테스트 배포 시작](https://render.com/deploy?repo=https://github.com/polarking1115/GPS) · [배포·로그인 안내](docs/free-test-deployment.md)

Render 계정과 GitHub 저장소 접근을 연결한 뒤 관리자 이메일·비밀번호를 보안 설정에 입력하면 `render.yaml`로 테스트 서비스를 만들 수 있습니다. **위 링크는 배포 시작 화면이며 앱 접속 주소는 배포 완료 후 Render가 발급합니다.** 무료 서비스는 휴면·재시작 때 DB·이미지가 초기화될 수 있으므로 실제 개인정보를 입력하지 마세요. 외부 호스팅 배포 완료·실제 접속 성공은 아직 확인하지 않았습니다.

## 다른 컴퓨터에서 이어서 작업

```bash
git clone https://github.com/polarking1115/GPS.git
cd GPS
git switch main
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

Windows에서는 `python3` 대신 `py -3.12`, `.venv/bin/python` 대신 `.venv\Scripts\python.exe`를 사용하세요. 비공개 저장소인 경우 해당 GitHub 계정으로 인증해야 합니다.

실행 후 브라우저에서 `http://127.0.0.1:8000`을 열고, `/manage`에서 새 개발 환경의 첫 관리자 계정을 생성합니다.

**GitHub에는 코드·문서·디자인만 포함됩니다.** 기존 `.data/` 개발 DB·암호키·계정·환경 변수는 포함되지 않습니다. 새 컴퓨터에서는 샘플 데이터로 시작합니다. 기존 개발 데이터까지 옮길 필요가 있다면 비공개 백업의 DB와 encryption.key를 함께 안전한 경로로 옮겨야 하며 Git에 추가하면 안 됩니다.

이어서 할 일은 [작업 재개 메모](docs/RESUME.md), 구현 범위는 [구현 현황](docs/implementation-status.md), 외부 서비스 후보는 [연동 검토](docs/integration-options.md)를 확인하세요.

## 실행

Python 3.12 이상에서:

```bash
cd /workspace/GPS
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

기본 주소는 `http://127.0.0.1:8000`입니다.

- `/`: 공개 행사 선택 및 참가자 앱
- `/manage`: 운영본부. 최초에는 **로컬 접속에서 첫 관리자 생성**. 이메일·표시명·12자 이상 비밀번호를 직접 지정합니다. 기본 비밀번호는 없습니다.
- `/register?event=youth-expo`: 부스 등록
- `/booth`: 부스 공동 관리 로그인
- `/bm/<관리 코드>`: 담당자 전용 주소. 공통 비밀번호와 담당자 표시명으로 접속
- `/b/<인증 코드>`: 현장 부스 QR 인증. 인증 코드는 공개 부스 API에 포함하지 않습니다.
- `/e/<행사 ID>`: 행사별 참가자 화면
- `/invite?code=<초대 코드>`: 24시간 유효·1회용 운영자 초대

최초 샘플 행사 `youth-expo`는 현재 한국 날짜로 생성되어 로컬 인증 테스트를 할 수 있습니다. 실제 행사 날짜·내용으로 변경하세요. 샘플 부스 비밀번호는 무작위이며 알 수 없게 설정합니다. 총괄이 **공간·부스 → QR·접근 → 공통 비밀번호 초기화**에서 설정해야 합니다. 참가 인증 QR도 여기서 다운로드할 수 있습니다.

## 구현한 흐름

- 행사 개설·설정 복제(존·부스·지도·미션·프로그램·설문), 초대·행사별 역할, 작업 이력
- 존과 부스 등록·승인·정보 수정, 여러 기기의 부스 공동 관리, 비밀번호 변경 시 기존 세션 회수
- 키비주얼 이미지·대표 색상 등록, 앞서 검토한 청록·파랑 계열 참가자 UI
- 부스 고정 QR SVG 다운로드와 브라우저 인쇄/PDF 저장
- 초기 개인정보 입력 없이 패스 생성, HttpOnly 쿠키 연결, 복구 기능 없음
- 서버 운영 상태·기간 확인, 동시 재시도 중복 방지, 별점 또는 평가 없이 인증
- 일별/행사 누적 부스 고유 패스 집계, 존은 부스별 참여자 합계, 평가 수·분포
- 부스/존 개수 미션, 퀴즈, 글 제출·운영자 검토
- 프로그램 일정·관심 일정(기기 저장), 공지
- 전체 설문 붙여넣기 인식 초안·표준 문항 추가·편집·공개, 응답 후 문항 변경 차단
- 행사별 설문·응모 조건, 연락처 정규화+HMAC 해시 기반 최초 유효 응모 1건
- 추첨 마감 확인·무작위 추첨·재추첨 차단·실행 대상 기록, 상품권 CSV·발송 결과 관리
- 대상별 업무 알림·부스 단위 확인, 유형별 문의·대화·처리 상태
- 지정 권한 안전 신고·답변·열람 이력. **기본 비활성**이며 현장 대응 준비 후 활성화
- 부스당 운영 실적 설문, 참가자 설문 집계·본인 지출 합계, 부스 CSV·보고서 인쇄
- 건물별 통합 평면도 업로드·부스 클릭 배치·확대. 층 선택 없음
- 일반 지도(OSM)·위성/항공사진(Esri) 배경, 등록 보행로 경로·거리·GPS 출발지 제안
- 야외 배치도 이미지 이동·모서리 크기·회전·투명도 편집, 보행 지점·통로의 지도 클릭 등록·드래그·폐쇄
- 건물 입구·외곽·오차·연속 수신 기준의 실내외 자동 전환, 수동 선택·GPS 중지
- 공개 API, 같은 출처에서 사용할 수 있는 부스 목록 위젯
- 한국어·영어 기본 메뉴, Google 번역 API 초안·운영자 검토·원문 변경 시 재검토, 타 언어 Chrome 번역 안내
- 운영자 대시보드·참가자 안전 화면의 행사장별 기상청 관측·초단기예보, 격자 계산, 1분 자동 확인, 서버 공유 캐시·지연 안내
- 모든 화면·메뉴와 팝업의 이용방법 버튼, 실제 입력칸·버튼 강조 튜토리얼, 이전/다음/종료·키보드 안내
- 공개 안내·이미지의 오프라인 캐시. 개인정보 API·응모·신고는 캐시하지 않음

## 미연결 또는 추가 제작 대상

사용자 기획에서 제외한 것이 아니라, 현재 구현 범위를 투명하게 구분한 목록입니다. [구현 현황](docs/implementation-status.md)을 참고하세요.

- 야외 지도·위성 배경·배치도 편집·GPS 전환은 구현했습니다. 현재 클라우드의 외부 타일 요청은 네트워크 프록시에서 403으로 차단되어, 실제 타일 수신은 미검증입니다. 배경 실패 시 안내·배치도·등록 통로는 유지합니다. 상용 보행 API·행사장 밖 경로 연결과 실제 현장 GPS 점검은 남아 있습니다. 외부 타일의 사용 조건·요금·트래픽 한도를 운영 전에 확인하세요.
- Google 번역 API와 검토·공개·원문 해시 추적은 구현했습니다. 현재 Codex 환경에는 키가 등록·주입되어 있지만, 실제 권한/과금 설정과 실서비스 호출은 아직 검증하지 않았습니다. 별도 배포 환경에는 키를 따로 등록하며, 키 없이도 수동 번역 작성·공개는 가능합니다.
- 기상청 현재 관측·초단기예보 API와 서버 캐시는 구현했습니다. 현재 Codex 환경에는 키가 등록·주입되어 있지만, 서비스 승인·격자 확인 및 실서비스 호출 검증은 필요합니다. 현재 특보 자동 연동은 제공하지 않으며 기상청 공식 특보 페이지로 연결합니다.
- 상품권 구매·자동 발송 API: 미연결. 외부 서비스용 CSV와 수동 결과 기록 제공.
- 탄소 배출/감축·사회적 편익·지역경제 확대 추정: 계수·기준 검증 전 산정하지 않습니다. 설문 수집·기초 집계만 작동합니다.
- 만 14세 미만 설문: 법정대리인 동의 확인 구현 전 **개인정보 설문 제출 차단**. 일반 안내·참여는 유지됩니다.
- 신고 사진·동의 예외 연락처, 파일첨부 메시지, 웹 푸시·예약 공지·재알림·입력 중 표시·문의 사진: 추가 제작.
- 미션 사진·글 재제출 요청·예비 당첨 승계·연락처 정정·정교한 데이터 삭제/보관 스케줄: 추가 제작.
- 외부 홈페이지 iframe: 기본 CSP는 `frame-ancestors 'self'`. 실제 아임웹 도메인을 확인하고 `FESTIVAL_EMBED_ORIGINS=https://your-site.imweb.me`로 허용 출처를 지정하세요. 해당 출처에만 iframe과 공개 GET API CORS를 허용합니다. 임의 `*` 허용은 하지 않습니다.

## 보안·운영

- `.data/`는 비공개 데이터·암호키·DB/WAL 저장소입니다. Git에서 제외하며 디렉터리 0700, 키 0600을 사용합니다. **암호키가 사라지면 암호화한 자료를 복구할 수 없습니다.** DB와 키를 접근 제한된 백업으로 함께 보관하세요.
- 연락처·설문 원자료·민감 신고 본문은 Fernet 암호화, 중복 판정 번호는 HMAC 해시, 비밀번호는 scrypt 해시로 저장합니다. 메모리·다운로드·백업·관리자의 접근 정책은 별도로 필요합니다.
- 참가자 쿠키는 HttpOnly·SameSite=Lax. HTTPS 배포 시 `FESTIVAL_SECURE_COOKIE=1`을 설정하세요. 운영자 토큰은 탭의 sessionStorage에 12시간 유효하게 보관합니다.
- 민감 신고는 `support` 권한으로만 열람합니다. 총괄도 이 권한을 별도로 받아야 합니다. 참가자는 자기 세션의 답변만 조회합니다.
- 참가자 고유 패스는 실제 사람 신원 인증이 아닙니다. 연락처 입력도 소유 확인을 보장하지 않습니다. 중복 응모 정책은 번호 기준입니다.
- 첫 관리자 설정은 기본 loopback 바인딩에서만 사용하세요. 인터넷 공개 전 관리자 생성 후 `FESTIVAL_ALLOW_SETUP=0`, HTTPS 역방향 프록시, 원본 접근 차단, 백업·모니터링·부하 검증을 적용하세요. 기본 HTTP 서버는 개발용입니다.
- 개인정보 동의문·연령 처리·보관 기간은 운영자가 적법한 내용을 검토해 설정해야 합니다. 설문은 동의문 없이는 공개되지 않습니다. 법적 검토 완료를 뜻하지 않습니다.
- 서버 로그에는 요청 URL·본문·토큰을 출력하지 않습니다. 민감 원자료 삭제는 되돌릴 수 없으며 백업·내려받은 파일 삭제는 별도입니다.

## 야외 지도와 자동 실내외 전환

1. 운영본부 → 공간·부스 → 통합 지도 편집에서 건물별 통합 평면도를 등록합니다.
2. ‘야외 지도·배치도·보행로 편집’을 엽니다. 일반/위성/배경 없음 중 선택합니다.
3. 배치도 이미지를 올리고 모서리·이동 핸들, 회전·투명도로 실제 위치를 맞춥니다.
4. 보행 지점을 지도에 추가하고 두 지점을 연결합니다. 지점은 드래그하고, 통로는 클릭해 폐쇄합니다.
5. 건물을 선택하고 입구와 외곽 두 모서리를 지정합니다. 자동 전환 사용, 반경·여유 거리·확인 시간·허용 오차를 설정합니다.
6. ‘현재 중심·확대 수준 저장’은 시작 화면을 설정하고, ‘공개 적용’은 편집 내용을 저장합니다. 닫기/취소는 적용하지 않습니다.
7. 참가자는 지도 화면에서 ‘GPS 안내 시작’을 선택합니다. HTTPS 또는 localhost에서 위치 권한이 필요합니다. 위치는 앱 서버로 전송하지 않습니다.

실내에서 입구와 멀어져도 건물 외곽 안이면 유지합니다. 신호 손실·낮은 정확도에서는 실내 지도를 유지하며, 건물 외곽 밖 여유 거리에서 연속으로 확인된 경우 야외로 복귀합니다. 수동 지도 선택 후 1분간 자동 전환을 유예합니다. 현재 층을 추정하지 않습니다. 인접 입구를 위치 오차로 구분할 수 없으면 자동 진입하지 않습니다.

배경 타일은 외부 제공자에 직접 접속하며 대량/오프라인 다운로드하지 않습니다. 외부 네트워크가 차단된 경우 ‘배경 없음’으로 편집할 수 있습니다. 위성사진과 현장 위치가 일치하는지 실제 장소에서 검증하세요. [타사 구성요소·지도 출처](docs/THIRD_PARTY.md)를 참고하세요.

## 검증

```bash
cd /workspace/GPS
.venv/bin/python -m unittest discover -s tests -v
node --check public/app.js
node --test tests/geofence.test.cjs
```

통합 테스트는 임시 DB와 별도 HTTP 서버를 사용하고 종료 후 정리합니다. QR 재시도/동시성·권한·미션·설문·중복 연락처·신고·추첨을 검증합니다.

브라우저 테스트는 Playwright와 Chromium이 있는 개발 환경에서 **새 임시 DB 서버**를 별도로 실행한 뒤 수행합니다. 실제 행사 DB에서는 실행하지 마세요.

```bash
FESTIVAL_DATA=/tmp/festival-browser-test PORT=8001 .venv/bin/python server.py
# 다른 터미널에서
BROWSER_TEST_URL=http://127.0.0.1:8001 node tests/browser-check.cjs
```

브라우저 검증은 실제 setup·로그인·인증·운영 중단·설문·문의·문항 편집과 모바일 넘침을 확인합니다. 이것은 1만 명 부하 검증이나 외부 서비스 연동 검증이 아닙니다.

### 임시 환경에서 브라우저 전체 검증

Node.js 22 이상, Playwright 및 Chromium이 준비된 환경에서 `node tests/run-browser.cjs`를 실행합니다. 새 임시 DB·포트를 자동 생성하고 테스트 후 정리합니다. 일반 흐름과 지도·배치도·GPS 전환을 함께 확인합니다. `BROWSER_PYTHON`으로 Python 경로, `CHROMIUM_PATH`로 브라우저 경로를 지정할 수 있습니다. 별도 지정하지 않으면 프로젝트 가상환경과 시스템 Chromium 또는 Playwright Chromium을 사용합니다.

외부 타일은 브라우저 테스트에서 대체 응답을 사용하므로 실제 제공자 연결 검증을 의미하지 않습니다. 화면 캡처는 기본적으로 임시 폴더에 저장하며, `BROWSER_SCREENSHOT_DIR`로 변경할 수 있습니다. 테스트를 실행해도 Git의 디자인 자료를 덮어쓰지 않습니다.

## 번역·기상청 연결

서버의 보안 환경 설정에서 아래 값을 등록하고 프로세스를 재시작합니다. 키는 Git·채팅·프런트엔드·관리 화면에 입력하지 않습니다. `.env.example`은 항목 안내일 뿐 자동으로 로드되지 않습니다.

| 변수 | 필요한 서비스 | HTTPS 목적지 |
|---|---|---|
| `FESTIVAL_TRANSLATION_API_KEY` | Google Cloud Translation Basic v2, API 사용·과금·키 제한 설정 | `translation.googleapis.com` |
| `FESTIVAL_KMA_API_KEY` | 공공데이터포털 기상청 단기예보 조회서비스 승인키, 초단기실황·초단기예보 | `apis.data.go.kr` |

### 영어 콘텐츠

운영본부 → 콘텐츠·일정 → 영어 번역·검토(또는 행사 설정 → 영어 번역 검토).

- 자동 번역은 한 번에 최대 30개/30,000자로 제한하며 호출 비용이 발생할 수 있습니다.
- 승인된 부스와 공개 미션·프로그램·공지, 행사 소개·존·설문 문항만 대상입니다. 연락처·설문 답변·신고·업무 메시지는 전송하지 않습니다.
- 생성 결과는 초안이며 ‘검토·공개’해야 영어 참가자 화면에 반영됩니다. 공지·동의문은 별도 검토 확인이 필요합니다.
- 원문이 바뀌면 기존 번역을 공개에서 제외하고 변경 표시합니다. 변경 중 생성된 초안도 원문 해시가 다르면 저장하지 않습니다.
- 설문은 선택지 라벨만 번역하고 제출 값은 한국어 원본으로 유지하므로 집계가 나뉘지 않습니다.
- 네트워크 요청 중에는 DB 쓰기 잠금을 해제해 부스 인증을 막지 않습니다.
- 공개 영어 데이터: `/api/events/<행사 ID>?lang=en`. 패스·설문도 `lang=en`을 지원합니다. 민감 신고 답변을 번역하지 않습니다.

### 날씨

행사 설정 → 연결 설정에서 ‘운영자 대시보드·참가자 안전 메뉴에 날씨 제공’을 켜고 지역명·기상청 nx/ny 격자를 등록합니다. 야외 지도 중심으로 격자 초안을 계산할 수도 있습니다. 실제 행사장과 대응되는 격자인지 확인하세요. 여러 지역을 등록하면 조회 지역을 선택할 수 있습니다.

운영자 대시보드의 ‘행사장 날씨’는 기온·습도·풍속·1시간 강수·초단기예보와 관측/수신 시각을 표시합니다. 화면이 보이는 동안 1분마다 확인하고, 서버는 행사 참가자의 호출을 공유해 최대 5분 캐시합니다. 현장 센서의 초 단위 실시간 측정은 아닙니다. 실패 시 같은 행사·같은 지역의 최근 자료에만 지연 표시를 붙이며, 1시간이 지난 값은 숨깁니다. 비공개 준비 행사의 날씨는 해당 행사 관리 권한이 있는 로그인에만 제공합니다. 기상청 특보는 공식 페이지 링크로 확인합니다.

### 화면별 이용방법

각 화면 상단의 **이용방법** 버튼을 누르면 현재 화면의 실제 메뉴·입력칸·버튼을 강조하며 사용 순서를 안내합니다. 팝업에서는 제목 옆 이용방법 버튼을 사용합니다. 참가자·운영본부·부스 담당자 메뉴와 로그인·등록·초대 화면을 지원합니다.

- **다음 / 이전 / 안내 마치기**, **안내 닫기**, 키보드 **Esc / ← / →**로 진행·종료합니다. Tab은 안내창 안에서 이동합니다.
- 안내가 실제 값을 입력하거나 저장·삭제·신고·추첨을 실행하지 않습니다. 작성 중 입력값은 유지하며, 입력칸의 값·비밀번호를 읽거나 외부로 보내지 않습니다.
- 안내 중 자동 화면 갱신을 잠시 멈춥니다. 종료 후 현재 화면에서 직접 작업을 진행하세요. 한국어·영어 안내와 공개 화면의 오프라인 캐시를 지원합니다.

### Render 테스트 사이트에 새 코드 적용

테스트 사이트: [참가자](https://gps-festival-demo.onrender.com/e/youth-expo) · [행사 운영자](https://gps-festival-demo.onrender.com/manage) · [부스 담당자](https://gps-festival-demo.onrender.com/booth).

자동 배포는 꺼져 있으므로 GitHub 업데이트 후 [Render 서비스](https://dashboard.render.com/web/srv-db9nktbbc2fs73cims7g) → **Manual Deploy → Deploy latest commit**으로 적용합니다. 관리자 환경 변수는 유지하세요. 무료 서비스는 재배포 시 테스트 DB·이미지·QR이 초기화될 수 있습니다. 날씨를 사용하려면 Render의 Environment에 `FESTIVAL_KMA_API_KEY`를 별도로 등록하고 행사 설정에서 날씨 제공과 기준 지역을 설정합니다. - 같은 격자는 5분간 서버 캐시를 공유하고 동시에 여러 참가자가 요청해도 한 번만 갱신합니다.
- 실패 시 1분 재시도 간격을 두고, 최근 1시간 이내 정상 자료만 ‘업데이트 지연’ 표시로 제공합니다. 그보다 오래되면 수치를 표시하지 않습니다.
- 날씨·번역 키의 존재 여부는 관리 화면에서 확인할 수 있지만 실제 인증 성공을 의미하지 않습니다.
- 자동 대피/부스 중단·실시간 낙뢰 감지·공식 특보 판정은 하지 않습니다. 공식 특보와 현장 안전계획을 확인해야 합니다.

`tests/test_integrations.py`와 브라우저 서비스 테스트는 대체 응답으로 검증하므로 실제 API 승인·사용량·요금을 검증한 것이 아닙니다.
