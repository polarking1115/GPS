# 이어서 작업하기 — 저장 시점

저장일: 2026-10-17 (Asia/Seoul)
최신 사용자 요청: 어제 작업의 남은 앱 기능 제작 계속하기. 2026-10-17에는 지도·배치도 편집·GPS 자동 실내외 전환을 구현하고 검증했다. 실제 운영 배포는 요청하지 않음.

다른 컴퓨터에서의 clone·실행 절차는 README.md의 첫 항목을 따른다. 원격 main에 저장하며 비공개 DB·암호키·계정은 전송하지 않는다. 새 기기에서는 새 개발 데이터로 시작한다.

## 현재 상태

- 기획 및 키비주얼 디자인 검토 후, 실제 DB 저장형 1차 개발 버전 구현.
- 실행: README.md 참고. 참가자 `/`, 운영본부 `/manage`, 부스 `/booth`.
- 개발 서버 기본 127.0.0.1:8000. 실행 중인 프로세스는 환경 재시작 후 유지된다고 가정하지 말 것.
- 첫 관리자 계정은 사용자가 직접 생성. 기본 비밀번호 없음. 테스트용 계정은 별도 임시 DB에만 생성.
- 실제 코드: server.py, public/. docs/prototype-v1.html은 이전 기획용 프로토타입.

## 유지할 핵심 결정

- 운영사가 여러 행사에 제공. 자유 출입·개인 참가, 예약 기능 제외.
- 참가 초기 개인정보 입력·기록 복구 제외. 같은 기기/브라우저 이용 안내.
- 운영자가 존 구성, 담당자가 존을 선택해 부스 등록. 부스당 QR 하나.
- 별점은 선택. 평가 없이 인증도 동일한 참여/미션 인정.
- 일시 중단·종료 시 서버에서 QR 인증 차단.
- 존 참여 인원 = 소속 부스별 참여자 합계. 부스 간 중복 제거하지 않음.
- 부스 담당자는 관리 QR+공통 비밀번호로 여러 명 동시 관리.
- 운영본부는 여러 개인 계정과 업무별 권한. 알림 확인 버튼·유형별 문의.
- 야외 길찾기, 실내 건물별 통합 평면도 한 장. 층 선택 없음.
- 하단 메뉴: 홈 / 프로그램 / 미션 / 안전 / 내 참여. 지도는 홈 바로가기.
- 미션은 신청/시작/모집 없이 수행. 부스 인증으로 반영, 별도 미션 QR 없음.
- 전체 설문 하나, 붙여넣기/표준양식 추가. 자격은 행사별 설정.
- 동일 연락처 최초 유효 응모 1건·중복 당첨 제외. 초기의 가족별 동일 번호 허용안은 폐기.
- 모바일 상품권 중심. 초기 외부 CSV 발송, 자동 API 미연결.
- 참가자/부스 탄소·지역경제 자료는 설문에서 수집. 근거 없는 감축·경제효과 수치 산출 금지.
- 키비주얼: 사용자 제공 제22회 대한민국 청소년박람회 포스터. 청록·파랑/분홍·노랑 포인트.
- 한국어/영어, 다른 언어 Chrome 번역 안내. 콘텐츠 번역 API 미연결.
- 안전·날씨·성희롱/불법촬영 신고. 민감 신고 별도 권한, 대응 체계 준비 전 비활성.

## 검증 기록

- 서버 HTTP 통합 테스트 10개 통과: 임시 DB 사용.
- Playwright: 관리자 생성, 존 등록, 부스 로그인, QR 인증, 중단 차단, 설문 응모, 문의, 설문 템플릿, 모바일 넘침 확인.
- 오프라인 공개 홈의 캐시/오래된 정보 안내, 영어 기본 메뉴 확인.
- 1만 명 부하·실제 현장 GPS·외부 공급자 API·배포 검증은 하지 않음.

## 다음 작업

1. 사용자와 실제 앱 화면을 보며 디자인·기능 수정.
2. integration-options.md의 후보 비교. 사용자는 기존 업체가 없으며 추천 조합 검토를 선택함.
3. 지도/보행·번역·기상 API 제공사·도메인·키 준비 후 연동. 키는 채팅·소스코드에 받지 말 것.
4. 상세 지도 편집·실내외 자동 전환, 추가 미션/메시지/보고서 범위 결정.
5. 미성년자 동의·보관/삭제·신고 대응 정책 검토. 현재 만 14세 미만 개인정보 설문은 차단.
6. HTTPS·배포·백업/복구·부하/현장 검증.

전체 범위/제약은 implementation-status.md, 기능 기획은 platform-spec-v1.md 참고.

## 데이터 주의

.data/는 Git에서 제외. DB와 encryption.key는 함께 보존해야 암호화된 자료를 읽을 수 있음. 비밀번호·키·연락처를 로그/채팅/저장소에 노출하지 말 것. 코드 백업에 운영 데이터가 포함됐다고 가정하지 말 것.

- public/map-ui.js: 참가자 지도와 GPS, 운영본부 지도 편집 UI.

- docs/THIRD_PARTY.md: Leaflet 출처·해시·라이선스, 지도 제공자·검증 한계.

다음은 실제 네트워크/현장에서 타일·GPS 동작 확인, 번역·공식 날씨 API 선택과 키 연결 단계다. API 키를 채팅에 요구하지 말 것. 타일은 현재 환경에서 403 차단되며, 실제 라이브 수신 성공을 주장하지 말 것.

후속 검증 결과: Python HTTP/설정 테스트 15개, Node GPS/기하 테스트 9개 통과. 기존 참가·부스·운영 흐름과 신규 지도 브라우저 테스트 모두 통과. 지도 타일은 대체 응답·GPS는 모의 위치로 테스트했으며 현장 검증은 아님. QR 미리보기 이미지가 실제로 렌더되는지도 브라우저에서 확인함.


## 번역·날씨 제작 추가 기록

사용자가 진행이 중단된 이유를 물었고, 설명만 반복하지 않고 번역·날씨 코드를 실제로 구현했다.

- integrations.py, translations.py, public/service-ui.js 및 tests/test_integrations.py, tests/browser-services.cjs 추가.
- 영어 초안 생성·수동 편집·검토 공개·원문 변경 추적, 개인정보 비전송, 설문 선택지 원본 값 유지.
- 기상청 실황/초단기예보·격자 설정, 공유 캐시·오류/지연 처리, 공식 특보 페이지 연결.
- 현재 `FESTIVAL_TRANSLATION_API_KEY`와 `FESTIVAL_KMA_API_KEY`는 미등록. 환경 설정에 등록할 요구사항 초안을 추가했고, 이는 키 입력/실행/게시 완료를 의미하지 않는다.
- 고급 산정·상품권 자동 발송·미성년자 동의·배포/부하 검증 등 전체 앱의 나머지 항목은 implementation-status.md를 확인한다.
- 실제 공급자 호출은 키가 없어 검증하지 않았다. 테스트는 대체 응답을 사용한다.

검증 추가: Python 통합/공급자 테스트 28개와 GPS 테스트 9개 통과. 일반 사용·지도·서비스 설정 브라우저 흐름 3종 통과. 영어 설문 선택지의 원본 값 유지, 수동 영어 검토/공개·원문 변경, 날씨/지연 화면, 오프라인 서비스 모듈 로드와 안전 화면 실패 안내까지 확인했다. 공급자 응답과 GPS/타일은 테스트 대체 응답이며 실키 호출 성공을 의미하지 않는다.
