# 화면 문구·영어·날씨 설정

행사 총괄 계정으로 [운영본부](https://gps-festival-demo.onrender.com/manage)에 로그인하고 해당 행사를 선택합니다. 배포 상태는 [작업 재개 기록](RESUME.md)의 최신 기록을 확인하세요.

## 주석으로 표시한 문구 수정

| 화면 문구 | 수정 위치 |
|---|---|
| 홈 제목의 ‘제22회’ | 행사 설정 → 행사명. 회차를 포함한 행사명 전체를 입력하고 저장 |
| 상단 앱 이름 | 모든 참가자 화면에서 **Grow Youth**로 고정. 행사 설정과 분리 |
| 행사 소개·장소·기간 | 행사 설정 → 행사 소개·장소·시작일·종료일 저장 |
| ‘샘플 행사 · 날짜는 개발 검증용’ | 참가자 홈에서 제거. 이전 표시 설정이 남아 있어도 표시하지 않음 |

이미지에 새겨진 글자는 위 설정으로 수정되지 않습니다. 키비주얼 설정에서 글자 없는 배경 이미지나 새 원본 포스터를 등록하세요. 무료 테스트 환경의 데이터 초기화 안내는 홈 샘플 문구와 별도입니다.

## 영어 전환

참가자 화면의 한국어 / EN 버튼은 홈·프로그램·지도·부스 인증·미션·안전·신고·내 참여·설문 및 관련 팝업의 고정 안내와 버튼을 전환합니다. API 키가 필요하지 않습니다. 설문·신고 입력값과 제출할 선택지 원래 값은 언어 전환 때 유지됩니다.

행사명·소개·존·부스·프로그램·공지·미션·퀴즈 질문·설문 문항·선택지·동의문·지도 지점·날씨 지역명은 운영자가 등록하는 콘텐츠입니다. 행사 설정 → 영어 번역 검토에서 영어를 작성하거나, Google 번역 키 연결 후 ‘미번역·변경분 자동 번역’으로 초안을 만드세요. 한 번에 최대 30개이므로 남은 항목을 확인하며 이어서 실행합니다. 번역을 검토·공개하면 참가자에게 표시됩니다. 안전 공지·동의문은 별도 확인이 필요합니다.

원문을 바꾸면 해당 번역은 재검토 전 한국어 원문을 표시합니다. 이미지 속 글자, 참가자가 입력한 설문·신고·답변, 비공개 운영 메시지는 자동 번역 API에 보내지 않습니다. 기본 청소년박람회 콘텐츠는 검토한 영어 번역을 함께 제공합니다. 사용자가 수정한 원문이나 검토 번역을 초기화하지 않습니다. 다른 언어 안내에는 한국어·영어 실제 앱 캡처와 Chrome 번역 메뉴 예시를 표시합니다. Chrome 메뉴 예시는 설명용으로 구성했으며 실제 메뉴는 기기·버전에 따라 다릅니다.

## 날씨 켜기

2026-10-20 공개 테스트 사이트 점검 시 행사 날씨는 비활성이고 Render의 날씨·번역 API 키는 미등록이었습니다. Codex 개발 환경의 키는 Render로 자동 전송되지 않습니다.

1. 공공데이터포털에서 ‘기상청 단기예보 조회서비스’ 활용 신청 후 인증키를 준비합니다.
2. [Render 서비스](https://dashboard.render.com/web/srv-db9nktbbc2fs73cims7g)의 Environment에 `FESTIVAL_KMA_API_KEY`를 보안 입력하고 저장·재배포합니다. 키는 소스나 채팅에 입력하지 않습니다.
3. 행사 설정 → 연결 설정에서 ‘운영자 대시보드·참가자 안전 메뉴에 날씨 제공’을 켭니다.
4. 실제 행사장에 맞는 기상청 격자 지역을 등록합니다. 야외 지도 중심을 실제 장소로 맞춘 뒤 ‘야외 지도 중심으로 격자 추가’를 사용할 수 있습니다. `60, 127`은 서울 예시이므로 여수에 그대로 사용하지 않습니다.
5. 날씨 설정 저장 → 연결 설정을 다시 열고 ‘저장된 설정으로 연결 확인’을 누릅니다. 행사 설정 꺼짐, 키 누락, 공급자 오류, 관측값 수신을 구분합니다.

참가자는 안전 → 날씨 새로고침으로 다시 확인할 수 있습니다. 화면은 1분마다 확인하고 서버는 최대 5분 캐시를 공유합니다. 기상청 발표 관측·예보이며 현장 센서나 특보 자동 판정이 아닙니다. 연결 실패 시 가짜 수치는 표시하지 않습니다.

## Render에 새 코드 반영

Render 서비스 → Manual Deploy → Deploy latest commit. Live 상태를 확인하고 앱을 새로고침하세요. 코드 배포와 별개로 운영자가 입력한 콘텐츠의 영어 번역 검토는 행사별로 관리합니다.
