운영 원칙과 데이터 해석

• 참가 초기 이름·생년월일·연락처 입력을 요구하지 않습니다. 추첨 연락처는 설문 단계에서 수집합니다.

• 인증 참여는 현재 체류 인원이 아닙니다. 존 참여 합계에는 여러 부스를 이용한 참가자가 중복 포함됩니다.

• 탄소 절감·사회적 비용·지역경제 효과는 기준·계수 검증 후 산정합니다. 현재는 원자료 수집과 기초 집계를 제공합니다.

• 날씨는 외부 API·지역 설정이 필요하며, 상품권 자동 구매·발송 API는 아직 연결되지 않았습니다.
