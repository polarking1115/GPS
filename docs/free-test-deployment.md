# 무료 테스트 주소 만들기

Render의 무료 Python 웹 서비스에 이 앱의 별도 테스트 복사본을 배포합니다. GitHub에 저장된 `render.yaml`을 읽는 Blueprint 방식을 사용합니다. 클라우드 환경의 **게시**는 개발 환경 저장이며 앱의 인터넷 배포와는 별개입니다.

[Render에서 테스트 배포 시작](https://render.com/deploy?repo=https://github.com/polarking1115/GPS)

## 처음 한 번 할 일

1. 위 링크에서 Render에 가입·로그인합니다. GitHub 계정으로 로그인할 수 있습니다.
2. `polarking1115/GPS` 저장소 접근을 허용합니다. 비공개 저장소이면 해당 저장소에 대한 Render GitHub App 접근 권한이 필요합니다. 저장소를 공개로 바꿀 필요는 없습니다.
3. Blueprint에서 `render.yaml`, `main` 브랜치, `gps-festival-demo` 서비스를 확인합니다. 서비스의 인스턴스 유형은 **Free**여야 합니다. 현재 제공 조건이 달라 유료 요금제를 요구하면 배포를 진행하지 말고 조건을 다시 확인합니다.
4. 배포 화면의 보안 환경 변수에 `FESTIVAL_ADMIN_EMAIL`(관리자 로그인 이메일)과 `FESTIVAL_ADMIN_PASSWORD`(직접 정한 12~200자 비밀번호)를 입력합니다. 비밀번호를 채팅이나 GitHub 파일에 쓰지 마세요. 공용 기본 비밀번호는 없습니다.
5. Blueprint를 배포하고 서비스가 **Live** 상태가 될 때까지 로그를 확인합니다. 환경 변수 누락 시 서버가 열리지 않으며, 필요한 변수 이름만 오류로 표시합니다.
6. Render가 서비스 화면에 표시하는 실제 `https://…onrender.com` 주소를 엽니다. 이 문서의 배포 시작 링크는 참가자 앱 주소가 아닙니다. 배포 완료 전에는 실제 호스트 이름을 알 수 없습니다.

배포 버튼에서 비공개 저장소를 선택하지 못하면 Render Dashboard → **New → Blueprint**에서 GitHub를 연결하고 `polarking1115/GPS`를 선택합니다. `render.yaml` 경로를 사용하세요.

## 배포 후 확인

발급된 기본 주소 뒤에 다음 경로를 붙입니다.

| 화면 | 경로 |
|---|---|
| 참가자 샘플 행사 | `/e/youth-expo` |
| 행사 선택 | `/` |
| 운영본부 로그인 | `/manage` |
| 부스 담당자 로그인 | `/booth` |
| 테스트 부스 등록 | `/register?event=youth-expo` |
| 상태 확인 | `/api/status` |

- `/manage`에서 위에서 지정한 이메일·비밀번호로 로그인합니다. 최초 관리자 생성은 외부에 개방하지 않습니다.
- 관리자 화면에서 **공간·부스 → QR·접근**을 열어 샘플 부스의 공통 비밀번호를 설정합니다. 표시된 부스 관리 링크와 인증 QR로 여러 기기를 테스트할 수 있습니다.
- 홈·프로그램·미션·안전 화면, 샘플 부스 QR 인증·별점·운영 중단, 운영본부의 집계 갱신을 확인합니다. 실제 이름·연락처·민감 신고는 입력하지 않습니다.
- 원본 클라우드 DB·계정·암호키·참여 기록은 복사하지 않습니다. 별도의 새 샘플 DB가 만들어집니다.

## 무료 구성의 범위

- Render의 무료 웹 서비스는 유휴 상태에서 휴면하며, 다음 접속 시 기동 대기 시간이 생길 수 있습니다. 월 사용량 제한도 있습니다. 최신 조건은 [무료 서비스 안내](https://render.com/docs/free)를 확인합니다. 이 구성은 유료 DB나 유료 디스크를 생성하지 않습니다.
- **무료 서비스의 로컬 파일은 영구 저장되지 않습니다.** 재배포·재시작·휴면 시 SQLite DB, 업로드 이미지와 암호키가 사라질 수 있습니다. 이때 관리자도 배포 환경 변수로 다시 생성되고, 참가 기록·링크·QR은 새 데이터로 바뀝니다. 일시적으로 살아 있는 프로세스와 DB가 유지될 때는 시작 스크립트가 기존 계정·비밀번호·데이터를 변경하지 않습니다.
- 처음부터 테스트 안내가 모든 앱 화면 상단에 표시됩니다. 실제 행사 운영·개인정보 수집·1만 명 동시 접속 검증용 구성이 아닙니다.
- 번역·날씨 API 키 없이도 앱을 열 수 있습니다. 자동 번역과 날씨 실황은 각각 키·행사 설정이 있어야 작동합니다. Codex에 등록한 키는 Render로 자동 전송되지 않습니다. 필요 시 Render의 Environment에 `FESTIVAL_TRANSLATION_API_KEY`와 `FESTIVAL_KMA_API_KEY`를 별도로 등록합니다. Google 자동 번역에는 무료량 초과 요금이 발생할 수 있습니다.
- 자동 재배포는 꺼져 있습니다. 코드 변경을 적용하려면 Render에서 수동 배포합니다. 테스트 종료 후 서비스를 삭제할 수 있습니다.

## 설정과 검증

- `render.yaml`: Free 요금제, Python 3.12.12, 의존성 설치, 시작 명령, `/api/status` 상태 검사, HTTPS용 Secure 쿠키, 필수 관리자 변수.
- `deploy_demo.py`: 공개 서버 시작 전 관리자 생성, 비밀번호 해시 저장, 외부 초기 관리자 생성 차단. 기존 DB가 있으면 계정 변경 없음.
- `tests/test_deployment.py`: 새 프로세스로 배포 시작·인증·쿠키·QR 집계·재시작·설정 오류를 확인합니다. 외부 Render 계정의 실제 배포 성공을 뜻하지 않습니다.

로컬 검증 결과: 공식 Render JSON Schema 검증 통과, Python 테스트 31개 및 Node GPS 테스트 9개 통과. 배포 시작 명령으로 실행한 임시 서버에서 Playwright로 모바일 안내·홈·프로그램·관리자 로그인·대시보드와 가로 넘침·JS 오류 없음을 확인했습니다. 실제 Render의 빌드·배포·발급 주소는 계정 연결 후 확인해야 합니다.
