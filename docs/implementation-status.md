# 실제 구현 현황 — 2026-10-17

현재 단계는 **실제 저장·인증이 동작하는 로컬 개발 버전**이다. 운영 배포나 최종 기능 완성을 의미하지 않는다. 기획의 확정/추천 구분은 platform-spec-v1.md를 기준으로 한다. 기존 docs/prototype-v1.html과 이미지 시안은 참고 자료이며 실제 앱은 public/ + server.py다.

## 동작·검증한 핵심

- 최초 관리자 생성·개인 초대·역할·행사별 접근 제한.
- 부스 담당자 자율 등록·승인, 공통 관리 인증과 여러 접속, 비밀번호 변경 시 전 접속 회수.
- 실제 고정 QR SVG, 인증 코드의 공개 API 비노출, 부스 운영 상태·날짜의 서버 검증.
- 선택 별점, 중복·동시 인증 제어, 일별·누적 부스 집계와 존의 부스 합산.
- 인증형 미션 진행률·퀴즈·글 검토.
- 설문 표준양식·붙여넣기 인식·편집, 자격 검사, 동일 연락처 최초 유효 응모 1건.
- 응모 마감 후 무작위 추첨·재실행 차단, CSV·발송 상태 관리.
- 유형별 부스 문의·답변·처리 상태, 공지·대상별 업무 알림·명시적 확인.
- 민감 신고 별도 권한, 신고 답변, 암호화 원자료·열람/업무 기록.
- 참가자/부스 운영 실적 설문, 기초 지출·문항별 집계, 탄소 계수 미설정 시 산정 전 표시.
- 행사 복제 시 참가기록·연락처·권한·비밀번호 비복사. 부스 재승인·미션 재공개 필요.
- 참가자 주요 메뉴와 홈의 키비주얼 디자인을 실제 HTML/CSS로 구성.

## 배포 전 외부 준비

1. 지도/보행·번역·날씨 API 제공사와 키·허용 도메인·호출량·요금 확정.
2. 개인정보 동의·보관/삭제 기준과 만 14세 미만 법정대리인 동의 절차 검토. 미구현 상태에서 해당 설문을 허용하지 않는다.
3. 신고 대응 담당자·권한·연락망·업무 기준 준비.
4. HTTPS·원본 접근 제한·초기 설정 차단·암호키/DB 백업·복구·접근 로그 운영.
5. 실제 접속·인증·외부 API 부하 목표를 정하고 1만 명 행사 수준 부하·현장 GPS/통신 검증.
6. 상품권 업체 파일 형식과 발송 실패·재발송 기준 확정.

외부 서비스가 미연결인 기능은 실제 정보처럼 꾸며 표시하지 않는다. 탄소·경제 결과도 임의 계수를 넣어 산출하지 않는다.

## 2026-10-17 후속 제작

- 실제 지도 렌더러와 야외 배치도/보행로 편집 UI를 추가했다. 외부 타일은 옵션이며 실패 시 안내하고 로컬 경로·이미지를 유지한다.
- 건물 통합 평면도별 입구/외곽/진입 반경/이탈 여유/연속 수신 시간/허용 오차를 저장·검증한다. 신호 손실 시 실내 유지, 수동 전환 1분 유예, 중복/오래된 표본 거부, 인접 건물 모호성 처리를 추가했다.
- 실내는 층 선택 없는 통합 이미지 방식을 유지한다. GPS는 기기 안에서 처리하며 서버에 좌표를 전송하지 않는다.
- QR 미리보기 blob 이미지의 CSP 차단을 수정하고, QR 인쇄 시 배경 앱을 숨긴다.
- Windows에서도 Asia/Seoul 시간대를 사용할 수 있도록 tzdata를 고정 의존성에 추가했다.
- 브라우저 테스트의 하드코딩된 /workspace 캡처 경로를 없애고 임시 DB 기반 실행기를 추가했다.
- 외부 타일 API 요청은 이 클라우드에서 프록시 403 응답으로 차단됐다. 브라우저 지도 테스트는 대체 타일·모의 GPS로 검증하며, 실제 서비스 수신·현장 정확도를 검증했다고 주장하지 않는다.
- 번역·공식 날씨·상품권 자동 발송·산정 계수/보호자 동의·운영 배포는 여전히 미완료다.

## 번역·날씨 후속 연결

- integrations.py: 고정 HTTPS Google 번역/KMA 어댑터, 키 노출 없는 오류 처리, 다른 출처 리다이렉트 차단, 날씨 동시 요청 공유·캐시·백오프.
- translations.py: 공개 콘텐츠 화이트리스트, 초안·검토·원문 해시, 공개 영어 페이로드. 연락처·설문 답변·신고·업무 메시지는 전송하지 않음.
- 운영본부에 연결 상태·기상청 격자 설정·번역 생성/검토/수동 편집을 추가했다.
- 설문 번역은 선택지 라벨만 변경하고 응답 값은 원본을 유지한다.
- 현재 이 환경에는 두 공급자 API 키가 없다. 실서비스 호출·승인·과금/품질 검증은 미완료다. 키 미등록을 기능 코드 미구현과 구분한다.
- 법정 동의·안전 공지는 자동 번역만으로 공개되지 않는다. 날씨 특보는 공식 페이지 연결이며 현재 특보 자동 판정은 미구현이다.
