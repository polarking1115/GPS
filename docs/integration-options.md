# 외부 서비스 연결 후보

사용자 답변: 기존 업체 없음. 추천 조합으로 검토한다. 아래는 연결 후보이며 계약·최신 요금·약관 검토와 실 API 검증이 끝난 선정 결과가 아니다. API 키는 채팅/저장소가 아닌 보안 환경 설정에 입력한다.

| 분야 | 우선 검토 후보 | 선정 시 확인 |
|---|---|---|
| 국내 지도 | 카카오맵 또는 네이버 지도 JavaScript SDK | 웹 도메인 등록, HTTPS, 위성/항공 지도, 이미지 오버레이, 호출량·요금 |
| 야외 보행 경로 | 티맵 보행자 경로 API | 다른 지도에 결과 표시 허용 여부·조건, 행사장 내 통로 지원, 키 보관·호출 제한 |
| 행사장 내부 길 | 플랫폼에 등록한 보행 지점·통로 | 임시 울타리·폐쇄 구간·현장 검수, 일반 지도 경로와 연결 |
| 한국어·영어 번역 | Google Cloud Translation 또는 DeepL | 공개 콘텐츠 번역 품질, 사용량·비용, 저장/데이터 처리 조건 |
| 날씨 | 기상청 단기예보·특보 공공데이터 | 인증키·승인, 격자/지역 매핑, 시간·장애/지연 표시, 공식 특보 범위 |
| 모바일 상품권 | 기업 대량 발송 지원 업체의 CSV부터 | 번호 중복 정책, 실패·재발송, 발송 단가·정산·개인정보 처리 계약 |

## 권장 순서

1. 지도 SDK 하나를 먼저 선택한다. 현재 구현된 자체 보행 그래프는 행사장 내부 통로용으로 유지한다.
2. 행사장 밖 길찾기는 지도 앱 연결부터 검증하고, 지도 간 데이터 결합이 허용되는 경우에만 별도 보행 API를 조합한다.
3. 번역은 관리자가 등록한 공개 행사 콘텐츠만 전송한다. 참가자 연락처·설문 원자료·민감 신고는 전송하지 않는다.
4. 날씨는 서버에서 일정 주기로 가져와 공유한다. 참가자별 외부 API 반복 요청을 피한다.
5. 상품권은 외부 CSV 발송을 실제로 검증한 뒤 API 자동 발송으로 확장한다.

## 준비할 항목

실제 운영 도메인, 아임웹 홈페이지 출처, 사업자/서비스 계정, 예상 지도 로드·경로 요청량·번역 문자 수·문자/상품권 수량. 이 값 없이 요금이나 1만 명 수용 성능을 확정하지 않는다.
